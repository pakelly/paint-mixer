# 🎨 Paint Mixer

Subtractive paint mixing tool for Army Painter Warpaints Fanatic line.

- **Mix toward color** — input a target hex, get 2- and 3-paint mix ratios
- **Collection gaps** — analyze which colors your stash can't reach, suggests what to buy
- **Color model** — weighted geometric mean in linear RGB, evaluated with CIEDE2000 in CIE Lab space

## Usage

Open `paint-mixer.html` in any browser. No server needed — it's fully self-contained.

## Data

180 paints (162 acrylics + 18 metallics) with hex values sourced from community spreadsheets.
